КОНТРОЛЬ ДЕТАЛЕЙ НА КОНВЕЙЕРЕ — v6: САМООБУЧАЮЩИЙСЯ ИИ-АВТОПИЛОТ
================================================================

Состав
  conveyor_monitor_v6.py      — главная программа (тёмный интерфейс, 4 вкладки)
  ai_autopilot.py             — движок ИИ-автопилота
  conveyor_monitor_v5.py      — ручной режим (встроен во вкладку «Ручной режим»,
                                можно запускать и отдельно)
  requirements.txt            — список библиотек Python
  1_установить_библиотеки.bat — установка библиотек вручную (необязательно)
  2_запустить.bat             — запуск v6
  3_запустить_старую_версию_v5.bat — запуск только ручного режима
  Создаются сами:
  config.json                 — настройки ручного режима
  ai_config.json              — настройки ИИ-автопилота
  ai_database\                — база ИИ (снимки деталей, фоны, шаблоны, обучение)

Требования: Windows 10/11, Python 3.10+ (64-бит), драйвер Interception.

1. Библиотеки
   Ставятся сами при запуске 2_запустить.bat:
     * сразу: opencv-python, numpy, mss, pillow;
     * в фоне, если их нет: dxcam, easyocr. easyocr тянет PyTorch (1–2 ГБ), установка
       может занять 5–15 минут. При первом чтении очков easyocr ещё скачает модель
       распознавания (около 100 МБ).
   Вручную: 1_установить_библиотеки.bat (или pip install -r requirements.txt).

2. Драйвер Interception (один раз)
   а) Скачайте релиз: https://github.com/oblitum/Interception/releases (Interception.zip)
   б) В папке «command line installer» от имени администратора:
        install-interception.exe /install
   в) Перезагрузите компьютер.
   г) Файл library\x64\interception.dll положите рядом с программой.

3. Запуск
   2_запустить.bat. Без прав администратора программа предложит перезапуститься с ними.

Вкладки
  «Ручной режим»  — всё из v5: зона, 12 линий, шкала (подъём камеры), очерёдность линий.
  «ИИ-Автопилот»  — СТАРТ / СТОП, «Тест клика», «Открыть папку БД», счёт, точность,
                    состояние ИИ, все настройки.
  «Предпросмотр»  — что видит ИИ: столб, зона и цель, деталь, скорость, прогноз; маска
                    отделения от фона; оптический поток.
  «Логи»          — общий журнал (сохраняется в файл, можно оставить только сообщения ИИ).

Как запустить ИИ-автопилот
  1. Откройте игру. На вкладке «ИИ-Автопилот» нажмите «Выбрать область игры мышью» и
     обведите ТОЛЬКО игровое поле (без кнопок, таблиц рекордов и меню вокруг).
  2. По желанию выберите «область счёта» (только цифры очков). По умолчанию — авто.
  3. Сначала включите «Пробный прогон» и нажмите СТАРТ: ИИ будет только показывать
     прогноз без кликов. Проверьте на вкладке «Предпросмотр», что столб обведён зелёным,
     а деталь жёлтым.
  4. Выключите пробный прогон, нажмите СТАРТ (или F9) и переключитесь на игру.

Как ИИ работает
  * Столб — неподвижный объект внизу области. Его верх задаёт цель и зону над столбом.
  * Фон восстанавливается картой по пикселям без объектов, уточняется гистограммой цвета
    вокруг столба и текстурой. Давно неподвижный декор (облака, табло) уходит в фон.
  * Скорость детали — оптический поток Farneback + история положений (с ускорением),
    поэтому подходит для случайной скорости и «маятника».
  * Клик — когда прогноз места падения совпадает с центром столба, с учётом задержки
    системы, выученного времени падения и смещения тайминга. Таймер клика точный
    (не зависит от шага системного таймера Windows).
  * Оценка — очки на экране через easyocr (+2 идеал, +1 обычно, 0 промах). Если очки не
    читаются — по геометрии укладки.
  * Обучение тайминга — обучение с подкреплением (контекстный бандит по скорости детали)
    плюс поправка по измеренной ошибке попадания.
  * Виды деталей — серия снимков за пролёт превращается в шаблон (медиана) и гистограмму.
    Обрезанная после неточной укладки деталь сравнивается с левой и правой частью
    шаблона и с выученными искажениями, поэтому не считается новой деталью.
  * База (ai_database): blocks\type_NN (снимки, distorted — искажённые), backgrounds,
    towers, templates, library.json, rl_timing.json, learned.json.

Горячие клавиши
  F9 — старт / стоп ИИ-автопилота (из любого окна)
  F8 — отправка сигнала в ручном режиме (пока работает ИИ, ручной режим на паузе)
  Стрелки — двигать область / шкалу в ручном режиме

Клавиша клика: space, enter и т. д. или mouse_left / mouse_right (клик мышью в текущей
точке курсора). Всё идёт через драйвер Interception.

Очерёдность (ручной режим): своя очередь линий, например 1-2-3-4-5-6-7-8 с возвратом
к шагу 6 даёт 1-2-3-4-5-6-7-8-6-7-8-6-7-8…

Внимание: если игра онлайн и запрещает макросы, использование может привести к блокировке
аккаунта. Ответственность на пользователе.
