КОНТРОЛЬ ДЕТАЛЕЙ НА КОНВЕЙЕРЕ (v5)
==================================

Состав архива
  conveyor_monitor_v5.py  — программа (один файл)
  requirements.txt        — список библиотек Python
  1_установить_библиотеки.bat — установка библиотек (один раз)
  2_запустить.bat         — запуск программы
  config.json             — появится сам после первого сохранения настроек

Требования: Windows 10/11, Python 3.10+ (64-бит), драйвер Interception.

1. Библиотеки
   Запустите 1_установить_библиотеки.bat (или: pip install -r requirements.txt).
   Для режима захвата DirectX дополнительно: pip install dxcam

2. Драйвер Interception (один раз)
   а) Скачайте релиз: https://github.com/oblitum/Interception
   б) В папке «command line installer» запустите от имени администратора:
        install-interception.exe /install
   в) Перезагрузите компьютер.
   г) Файл library\x64\interception.dll (для 64-битного Python) положите рядом
      с conveyor_monitor_v5.py.

3. Запуск
   2_запустить.bat. Если программа запущена без прав администратора, она предложит
   перезапуститься от имени администратора (нужно для Interception).

Горячие клавиши и важные настройки
  F8                — включить / выключить отправку сигнала (работает из любого окна)
  Стрелки           — двигать область (вкладка «Зона») / шкалу (вкладка «Шкала»)
  «Тест клика»      — нажатие через 3 секунды, чтобы успеть переключиться на игру
  Настройки         — автосохранение в config.json каждую минуту и при выходе

Режимы
  «Зона»            — рамка / круг / ромб / вертикальная полоса, процент заполнения цветом
  «Цикличные линии» — до 12 линий; цикл идёт по включённым линиям по порядку;
                      выключенные пропускаются
  «Шкала»           — один слайдер сдвигает все линии по оси Y (подъём камеры)
  «Очерёдность»     — своя очередь линий вместо порядка 1→12: любые линии в любом
                      порядке, с повторами (кнопки 1..12 или строка «1-2-3-4-5-6-7-8»).
                      «После последнего шага — к шагу №» задаёт, откуда цикл
                      продолжается: шаги 1-2-3-4-5-6-7-8 и возврат к шагу 6 дают
                      1-2-3-4-5-6-7-8-6-7-8-6-7-8… Включается флажком «Использовать эту
                      очередь». Текущий шаг подсвечен зелёным, номер шага виден в шапке.

Совет: в режиме линий любое изменение пикселей считается срабатыванием, в том числе
возврат к фону. Если нужен только один клик на проход цели, держите «Пауза после
срабатывания» около 100 мс и больше.

Внимание: если игра онлайн и запрещает макросы, использование может привести к блокировке
аккаунта. Ответственность на пользователе.
